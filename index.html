One-time setup

No Traffic reads live traffic from Mapbox, which needs a free access token.

  1. Create a free account at mapbox.com and copy your default public token (it starts with pk.).
  2. In the project folder, create a file named .env.local containing:
    VITE_MAPBOX_TOKEN=pk.your-token
  3. Stop and restart npm run dev.
